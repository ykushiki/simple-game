# 3D Action コア仕様

## 既存要件（instruction.md 反映）
- 3Dグリッド移動のターン進行ゲーム。
- プレイヤー入力（移動/攻撃/ジャンプ）後に敵行動が進む。
- 敵撃破時のみスコア加算（50点）。
- 回復アイテム（リンゴ）は1フィールドにつき1個のみ出現。
- HP=0 のゲームオーバーで、画面中央にスコアを大きく表示する。

## 特徴的な内部仕様
- プレイヤーと敵の行動はターン単位で同期する。
- 敵はプレイヤーマスへの移動が可能。
- 被弾/接触ルールは「同ターン同マス」の扱いを重視する。
