# 3Dダンジョン表現仕様

## 指摘事項の反映
- 壁は巨大ブロックではなく、セル境界に立つ薄い壁セグメントで表現する。
- トーチは通路中央に浮かせず、壁面に取り付ける。
- 扉は壁線上に整合する向きで配置し、開閉アニメーションは一貫した方向で行う。
- 壁・閉扉越しのターゲット選択/攻撃は不可とする。

## 特徴的な内部仕様
- 壁材質は CanvasTexture ベースの map + bumpMap + roughnessMap を使用する。
- 床材質も同様に凹凸感を持たせた PBR 近似を使う。
- プレイヤートーチは PointLight + 微小パーティクル（灰/煙）を併用する。
- 壁トーチは壁法線に沿ってマウント位置を決定する。

## 実装ルール
- 壁セグメント生成時は、同一位置への重複生成を避ける。
- 扉は辺情報に基づいてヒンジ位置を決定する。
- 回転補間は最短角を採用し、右旋回で左へ大回りしない。

## 品質チェック
- 壁線と扉の向きがミニマップと3Dで一致していること。
- 開閉中の扉で鍵が重複消費されないこと。
- 扉開放後に通行可能状態へ遷移すること。
