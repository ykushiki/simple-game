# 画面上のMAP表現仕様

## 指摘事項の反映
- 未踏破セルは表示しない。踏破セルのみ可視化する。
- 踏破セルの周辺壁は線として見えること。片側しか見えない状態を許容しない。
- 壁の表現は塗りつぶしセルではなく、罫線ベースで描画する。
- 扉は壁線上の特別な線として表示し、開閉状態で視覚差をつける。
- モンスターやターゲット情報は遮蔽を尊重し、壁・閉扉越しに表示しない。

## 特徴的な内部仕様
- ミニマップは gameState.visited を真理値ソースとして描画する。
- 壁線は gameState.walls[z][x] の n/e/s/w 辺情報から描く。
- 同一壁線の重複描画を避けるため、エッジキーで描画済み管理を行う。
- 扉線は gameState.doors の辺情報（side, open）で描画を切り替える。

## 期待挙動
- プレイヤー移動後に MAP が即時更新される。
- 旋回時に方角インジケータが即時更新される。
- 壁線は視認できる太さ・色で表示される。
