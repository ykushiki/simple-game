# 地図データ構造仕様

## 指摘事項の反映
- 壁をセル値で持たず、セル境界（辺）で持つ。
- 扉はセル占有ではなく辺上の障害物として表現する。
- 鍵は必ず開始地点側で取得可能にし、進行不能マップを生成しない。

## 特徴的な内部仕様
- gameState.map: セル内容（EMPTY/CHEST/STAIRS など）
- gameState.walls: 各セルが持つ4辺の閉塞情報 { n, e, s, w }
- gameState.doors: 辺ベースの扉情報（x, z, side, axis, open, id）
- gameState.visited: 踏破済みセルの可視化状態

## 生成・探索ルール
- 迷路生成は DFS でセル間の辺を開閉して構築する。
- パス判定は「隣接セル + 辺が開いている + 閉扉でない」を満たすこと。
- 到達可能領域計算（BFS）で鍵配置の到達可能性を保証する。
- 扉候補は実際に開いている辺から選び、通路軸情報を保持する。

## 禁止事項
- TILE.WALL 前提で衝突判定・描画・ミニマップ判定を実装しない。
- 扉をセルに直接埋め込み、セル値で開閉状態を管理しない。
