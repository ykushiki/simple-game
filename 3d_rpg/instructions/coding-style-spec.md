# コード品質・命名規則

## 命名規則
- 定数は UPPER_SNAKE_CASE を使用する。
  - 例: MAP_SIZE, TILE_SIZE, WALL_THICKNESS
- 関数・メソッドは camelCase を使用する。
  - 例: generateDungeonMap, updateUI
- クラス名は PascalCase を使用する。
  - 例: SoundEngine

## 可読性とコメント
- 主要関数には、日本語で「役割」「引数」「戻り値」を明記する。
- 複雑なロジック（地図生成、辺ベース衝突判定、描画最適化）は意図が伝わるコメントを付ける。
- コメントは実装の意図を説明し、コードを言い換えるだけの冗長な記述は避ける。

## 運用
- 新規追加コードは上記規約に従う。
- 既存コードに大きな変更を入れる際は、関連箇所の命名とコメントも同時に整える。
